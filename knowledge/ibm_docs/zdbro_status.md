# ZDBRO STATUS: Display database reorganization status

Source: IBM z/TPF documentation - https://www.ibm.com/docs/en/SSB23S_2025/gtpo1/cmd_zdbrostatus.html

## Requirements and restrictions

You must enter the ZDBRO INIT command before you enter any other
ZDBRO command.
DBR must be running when you enter this command.

## Additional information

None.

## Examples

```
User: ZDBRO STATUS
System: DBRO0062I 22.12.33 DBR IS PRESENTLY PROCESSING
        RECORD TYPE 0000,ORDINAL NUMBER 000000000000013D,ECB= 00000020
```
